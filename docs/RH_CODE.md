# RH Code 使用指南

RH Code 是 PCL RH 的项目工作区。一个项目把源码文件夹、多个 AI 对话、Minecraft 版本与加载器目标组织在一起。顶部紫色入口打开工作区，旁边的橙色入口管理插件；百宝箱位于「设置」。

## 创建与打开项目

点击「新建项目」，填写名称并选择一个已有文件夹。空文件夹可用于新的模组工程，已有文件夹可用于阅读和编辑源码。项目登记不会移动文件夹。项目列表可以搜索名称和路径，工作区顶部可以直接切换项目。

默认登记 Fabric 和 NeoForge 目标。目标描述开发意图，不代表两个加载器的工程已经生成或编译完成。可以在「构建与测试」区域增加 Minecraft 版本，并分别选择加载器。

旧制作器和搬运器项目可从项目列表的「旧版项目」打开，继续使用兼容界面及原有任务产物。新工作区采用独立的项目记录，不会自动转换旧项目。

## 调整区域

每个区域顶部选择它显示的内容：内容图谱、文件图谱、源码、AI 对话、对话列表、构建与测试、版本迁移、改动审阅或任务输出。

- 区域操作菜单可左右或上下拆分、交换区域、关闭区域。
- 拖动分隔线调整大小；分隔线也支持方向键。
- 最大化按钮暂时聚焦一个区域，再次点击还原。
- 「布局」提供创作、并行对话和源码三种起点，并可保存、重命名和删除自己的布局。
- 保存的布局可跨项目套用，最多保留 32 个。导出生成可复制的 JSON；导入支持粘贴 JSON 或选择文件。
- 支持设置的组件会在区域标题旁显示齿轮。「项目概览」可调整是否显示目录，同一组件的不同区域各自保存设置。

布局随项目保存。关闭区域不删除对话、源码或任务；源码中尚未保存的编辑在当前启动器会话中保留。每个项目最多显示 12 个区域。

导出的布局只包含区域类型、位置和尺寸，排除文件路径、对话绑定与组件数据。套用时重新分配区域身份，AI 对话区域按当前项目的对话顺序绑定。组件暂不可用时保留区域占位，重新启用插件后恢复。组件显示出错时，可在该区域重新加载。

内容图谱目前按源码、资源和项目配置分组；文件图谱提供可折叠的目录树。它们尚未解析 Java 语义或 Minecraft 注册关系。

## 对话与 AI

左下角设置按钮管理共享 AI 预设、密钥和任务预算。保存并选中预设后，在项目对话中提交请求即可自动启动引擎。

高级设置中的模型调用、工具调用、单次输出、任务时长和估算费用上限均可设为 `0`，表示不设该项任务限制。输出仍遵循模型容量；预设修改用于新任务，运行中的任务保留原配置。

项目支持多个独立对话，同一对话一次运行一个任务，共享引擎最多运行两个任务。任务归属项目和对话，切换区域或页面不会取消它。停止按钮取消当前任务。

询问和规划采用只读工具范围；执行模式的源码建议继续经过改动审阅。近期上下文最多投影 8 条消息，每条截取最多 1800 字符；完整历史仍保存在项目记录中。源码摘要有独立字符预算。这是确定性的上下文投影，不是模型生成的长期记忆。

目前源码生成适配器支持 Fabric 1.21.1 的 Maker 工程。其他源码可用于询问和规划，尚不能通过这个适配器执行通用工程修改。构建、打包和启动测试按钮尚未接入项目构建服务。

## 源码与审阅

从文件图谱打开文本文件，修改后点击保存。保存检查文件内容指纹：磁盘文件被其他编辑器修改时，会拒绝覆盖，并保留原内容备份。文本文件上限为 1 MiB。

AI 使用 Rust 宿主捕获的源码快照，在单独任务副本中工作。生成后的源码先作为任务产物保留；「采用源码」只允许发布到所选的空项目文件夹。已有文件不会被这个操作覆盖。现有工程的 AI 改动仍保留为审阅后的独立副本，尚未提供合并回原文件夹的流程。

Maker 工程中手改的 Java 或资源源码，会在下一轮任务副本中更新保护记录并锁定，原文件夹的记录保持原样。修改构建控制文件或缺失保护记录中的文件，需要对应导入适配器，不能自动认作模板变更。

AI 源码快照当前最多 300 个文件、总计 256 KB。大型工程可以浏览和编辑，但超出快照范围时需要更精细的源码读取适配器。生成或审阅源码不代表 Java 编译和游戏测试已通过。

## 内置与社区插件

橙色插件入口中，内置模块可按依赖启停，核心项目服务与设置必须保留。插件停用时其区域显示占位，重新启用后恢复原区域；对话和文件缓冲区由项目服务持有。

每个内置插件可独立提供组件、组件设置、命令和布局。插件页显示运行状态及贡献清单；加载失败时可以重试，依赖未就绪的模块不会运行。

内置模块使用 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 所采用的 Cordis 生命周期机制。RH Code 接入了实际的 `@deepseek-ai/cordis`，Agent 执行由现有 Pi 适配器负责；没有装载 DSH 的整套默认插件，也不声明兼容 DSH 插件包。

社区入口继续使用声明型插件和原生权限管理，不执行第三方 JavaScript。市场暂未开放。内置模块的能力声明不等于社区插件授权，Cordis 本身也不是代码执行沙箱。旧格式范围见[兼容功能说明](EXPERIMENTAL.md)。

开发者可继续阅读[RH Code 模块结构](RH_CODE_ARCHITECTURE.md)及[内置插件开发](RH_CODE_PLUGINS.md)。
