# 账号与登录

## 离线玩家

选择「新建档案 → 离线验证」，填写玩家名称后保存，再选择游戏版本并点击「启动游戏」。离线身份可用于单人游戏及允许离线身份的服务器，无法用于要求正版身份验证的服务器。

## Microsoft 正版登录

在启动页选择「新建档案 → 正版验证」，或点击已有正版账号进入登录页。点击「登录 Microsoft 账号」后，启动器会尝试复制设备代码并打开微软登录网页；也可以用页面里的按钮再次复制或打开。

网页授权完成后，账号会加入列表。勾选「记住登录」可保存凭据；如果保存失败，可在当前会话中点击账号旁的「保存」重试。凭据保存在系统密钥环中，账号列表只保存公开档案信息。Linux 需要已启动的 Secret Service 密钥环，例如 GNOME Keyring；首次保存或密钥环锁定时可能出现系统密码提示。

正版账号会自动获取头像与当前佩戴的披风。点击服装图标查看，获取失败时可重试。图片获取失败不影响登录。

应用注册与服务接入由项目维护者完成，普通用户无需注册 Azure 应用或配置 Client ID。

登录失败会标明设备代码、微软凭据、Xbox 或 Minecraft 的具体阶段，区分连接失败、超时与服务返回的 HTTP 错误。先检查网络、代理和系统时间，再重试；服务限流或暂时不可用时稍后重试。HTTP 403 表示服务拒绝访问，不能单凭它判断应用审核或账号资格；持续出现时请将阶段与状态码提供给维护者，勿发送设备代码、令牌或密码。
